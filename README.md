# ORDO — 샘플실 포트폴리오 사이트

자켓·코트·셔츠·블라우스 패턴과 샘플을 만드는 샘플실 **ORDO**의 사이트예요.
설치하거나 빌드할 프로그램은 없고, 파일을 고치면 1–2분 뒤 사이트에 반영돼요(GitHub Pages).

## 페이지 구성

| 파일 | 페이지 | 하는 일 |
|---|---|---|
| `index.html` | Home | 첫 화면. 큰 문장과 대표 작업 4개 |
| `projects.html` | Projects | 작업 카드 목록. 마우스를 올리면 사진 위에 제목·설명 |
| `portfolio.html` | Portfolio | 사진 가로 한 줄. 마우스를 올린 사진이 커져요 |
| `work.html` | Work | 작업마다 크기가 다른 사진 무리를 자동 배치 |
| `project.html?id=작업id` | 작업 상세 | 세 갤러리에서 사진을 누르면 오는 곳 |
| `studio.html` | Studio | 소개 · 서비스 · 진행 과정 |
| `contact.html` | Contact | 연락처 · 의뢰 정리 폼 · 준비물 · FAQ |
| `check.html` | 점검 | 친구 전용. 데이터·사진 오류를 빨간색으로 보여줘요(검색에 안 나옴) |
| `404.html` | 없는 주소 | 처음 화면으로 돌아가는 안내 |

## 자주 고치는 곳

대부분은 `data/site.js`(기본 정보)와 `data/works.js`(작업 목록) 두 파일이면 돼요.
글 몇 군데는 페이지 파일에 직접 적혀 있어요. 아래 표를 보고 찾아가세요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 이름·연락처(카톡 채널·인스타·이메일·전화)·주소·운영시간·서비스 5개·진행 단계·경력·장비·리드타임 | `data/site.js` |
| 작업물(제목·사진·설명) | `data/works.js` |
| FAQ 6개 · 의뢰 전 준비물 문장 | `contact.html` 의 `4. 의뢰 전 준비물` 주석 아래 |
| Studio 소개 제목(Made by hands…)·두 문단·영문 소개 3줄 | `studio.html` 의 `Studio 소개 글` 주석 아래 |
| Projects·Contact 머리의 영문 소개 3줄 | `projects.html` · `contact.html` 맨 위 타이틀 블록 |
| 작업실 사진(Studio) | `images/site/studio.jpg` 로 올리기 — 세로 4:5, 500KB 이하 JPG |
| 공유 미리보기 이미지(카톡·인스타 링크 썸네일) | `images/site/og.jpg` 로 바꾸기 — 1200×630, 200KB 이하 |

- **주소·전화를 바꿀 때**: `data/site.js` 를 고치면 푸터·메뉴·Home·Studio·Contact·지도·하단 바가 같이 바뀌어요.
  다만 `contact.html` · `studio.html` 에 적힌 같은 번호·주소는 *자바스크립트가 꺼졌을 때만* 보이는 기본값이라,
  두 파일에서도 같은 글을 찾아 바꿔 주세요(파일 안 주석에 표시해 뒀어요).
- 카카오톡 채널 주소(`contact.kakaoUrl`)가 비어 있는 동안 모바일 하단 검정 버튼은 **[전화 문의]** 예요.
  채널 주소를 넣으면 자동으로 **[카카오톡 문의]** 로 바뀌어요.
- `assets/` 안의 파일(디자인·동작)은 고치지 않아요.
- `○○` 표시는 아직 정하지 않은 자리예요. 실제 값으로 바꿔 주세요. **가짜 전화번호·주소는 넣지 마세요.**

> **예시 사진 주의** — 지금 `images/works/` 안의 사진 79장은 화면 확인용으로 **AI가 만든 임시 사진**이에요(실제 ORDO 작업이 아님).
> 작업 설명·숫자(`data/works.js`)도 예시예요. 고객에게 보여주기 전에 실제 작업 사진과 내용으로 바꾸거나 지워 주세요(사진을 지우면 회색 사진 자리로 돌아가요).

## 작업물 추가하는 순서 (GitHub 웹에서만)

1. **사진 줄이기** — 긴 변 2000px, 장당 500KB 이하 JPG로(squoosh.app 추천).
   파일 이름은 **영어 소문자와 숫자**만: `01.jpg`, `d1.jpg`, `in1.jpg`, `p1.jpg`.
   아이폰 HEIC 사진은 JPG로 바꿔요. `.JPG`와 `.jpg`는 다른 파일로 취급돼요.
2. **사진 올리기** — 저장소의 `images/works` 폴더에서 *Add file → Upload files*.
   새 폴더(예: `coat-13`)째 올려요. 폴더 이름 = 작업 id.
3. **목록에 적기** — `data/works.js`의 연필 아이콘 → 파일 맨 위 주석의 *복사용 예시 블록*을 복사해
   `window.WORKS = [` 바로 다음 줄에 붙여넣고, 따옴표 안의 값만 바꿔요. → *Commit changes*.
4. **확인** — 1–2분 뒤 사이트의 `check.html`을 열어 빨간 표시가 없는지 봐요.

### works.js에서 알아 둘 것

- 꼭 있어야 하는 칸: `id`, `category`, `title`, `look`. 나머지는 비우면 화면에서 그 줄이 자동으로 숨어요.
- `category`는 `jacket` / `coat` / `shirt` / `blouse` 중 하나.
- **목록 순서 = 화면 순서.** 맨 위 작업이 (001)번이에요.
- `hidden: true` → 지우지 않고 숨기기. `client`를 비우면 *Private client*로 보여요.
- 사진 칸은 두 가지로 적을 수 있어요.
  - 파일 이름만: `"01.jpg"`
  - 비율까지: `{ src: "02.jpg", ratio: "3:2" }` → 사진이 아직 없을 때 회색 자리의 모양을 그 비율로 잡아요.
  - 비율을 안 적으면 기본값: look 4:5 · detail 1:1 · inside 4:5 · pattern 3:2.
- 사진이 아직 없으면 회색 칸과 `LOOK 01 · 4:5` 같은 라벨이 보여요. 이 라벨이 그대로 **촬영할 컷 목록**이에요.
  사진 파일을 올리면 자동으로 사진으로 바뀌어요.

### 사진 규칙

- 흰색·연회색 무지 배경, 같은 조명.
- 작업마다: 앞·뒤·옆(look) + 디테일 2–4컷(detail) + 안쪽 1컷 이상(inside: 안감·심지·시접) + 있으면 패턴지·토일(pattern).
- 공개 저장소라서 **원본 고해상도는 올리지 않아요.**
- 올리기 전에 고객에게 **공개 동의**를 받아요. 출시 전 작업은 `hidden: true`로.

## 실수했을 때

- `works.js`나 `site.js`에 쉼표·따옴표가 빠지면 사이트 위쪽에
  *“data/works.js ○번째 줄 근처의 쉼표·따옴표를 확인해 주세요”* 안내가 떠요. 사이트 전체가 하얗게 죽지는 않아요.
- 필수 칸이 빠진 작업은 그 작업만 건너뛰고 나머지는 정상으로 보여요.
- `check.html`은 사진 누락, 파일 이름 대소문자·확장자 불일치(`Coat.JPG` ↔ `coat.jpg`), 카테고리 오타, 비율 형식 오류를 찾아 줘요.

## 저장소를 넘기거나 주소가 바뀔 때

- 사이트 안 링크는 모두 상대경로라 그대로 동작해요.
- **유일한 예외: 공유 미리보기 이미지(og:image).** 모든 `.html` 파일 맨 위의
  `https://endlineathletics.github.io/sample-room/images/site/og.jpg` 한 줄을 새 주소로 바꾸고,
  카카오 공유 디버거(developers.kakao.com → 도구 → 공유 디버거)에서 캐시를 초기화해요.
- github.io 주소가 바뀌니 인스타 프로필 링크는 저장소를 넘긴 **뒤에** 걸어요.
- `.nojekyll` 파일은 지우지 마세요(GitHub Pages가 파일을 그대로 보여주게 해요).

## 로컬에서 미리 보기

`index.html` 을 더블클릭하면 이 컴퓨터에서 바로 열려요. 화면 모양을 보는 데는 이것으로 충분해요.

- **사진 파일 이름 점검은 꼭 올린 사이트 주소의 `check.html` 에서** 해 주세요.
  맥·윈도우는 `01.JPG` 와 `01.jpg` 를 같은 파일로 보기 때문에, 이 컴퓨터에서는 정상으로 보여도
  GitHub Pages 에서는 사진이 안 나올 수 있어요(이 컴퓨터에서 연 `check.html` 에도 같은 안내가 떠요).
- 더블클릭으로 열면 데이터 파일 오류 안내에 '몇 번째 줄' 이 빠질 수 있어요. 줄 번호도 사이트 주소에서 열면 보여요.
